## Tutorial Summary

### Week 1
Created the GitHub repository and completed basic Java programs including HelloWorld and StudentGrade.

### Week 2
Learned how to create a Student class with attributes, constructors and methods. Created objects and called methods from the Main class.

### Week 3-4
Learned inheritance and polymorphism by creating Person, Student and Lecturer classes. Student and Lecturer inherited properties and methods from Person and overrode the introduce method.

### Week 5
Learned encapsulation by declaring student information as private and accessing the data using getters and setters.

### Week 6
Practised inheritance using Employee as the parent class and Lecturer as the child class. Used the super keyword to call the parent constructor.

### Week 7
Learned abstraction by creating an abstract Appliance class and implementing different appliance classes with their own operate methods.

### Week 8-9
Learned how to use ArrayList to store tasks and Java file handling to save tasks into a text file and read the saved information.

### Week 10
Developed a simple Java Swing Programming Quiz Battle application using JFrame, JLabel, JButton and ActionListener.

## How to Run the Projects

1. Open the repository using GitHub Codespaces or Visual Studio Code.
2. Open the terminal.
3. Navigate to the required tutorial folder.
4. Run the Java program using:

java Main.java

For Week 10, compile and run the GUI application using:

javac Questions.java QuizBattleGUI.java

java QuizBattleGUI
